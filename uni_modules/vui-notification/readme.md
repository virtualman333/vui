# vui-notification

VUI 通知组件

## 属性
- modelValue 是否展示，支持 v-model
- title 标题
- message 内容
- type primary / success / warning / error / info
- position top-right / top-left / bottom-right / bottom-left
- duration 自动关闭时间
- show(opts) 通过 ref 调用

## 使用示例

```html
<vui-notification />
```

更多示例请参考项目演示页 `pages/demo/demo.vue`。
