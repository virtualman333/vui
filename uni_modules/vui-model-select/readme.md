# vui-model-select

VUI 模型选择组件

## 属性
- modelValue 选中值，支持 v-model
- options 模型列表 [{ label, value, desc, tag, icon, disabled }]
- title 弹层标题
- placeholder 占位文案
- disabled 是否禁用
- clearable 是否可清空
- showDesc 是否在触发器上显示当前模型描述

## 使用示例

```html
<vui-model-select />
```

更多示例请参考 AI 组件演示页 `pages/demo/ai.vue`。
