# vui-chat-input

VUI AI 对话输入框组件

## 属性
- modelValue 输入内容，支持 v-model
- placeholder 占位文案
- disabled 是否禁用
- loading 是否处于生成中（显示停止按钮）
- autoHeight 是否随内容自适应高度
- maxlength 最大输入长度
- showCount 是否显示字数
- sendText 发送按钮文案
- stopText 停止按钮文案
- showVoice 是否显示语音入口
- confirmType 键盘右下角按钮类型

## 使用示例

```html
<vui-chat-input />
```

更多示例请参考 AI 组件演示页 `pages/demo/ai.vue`。
