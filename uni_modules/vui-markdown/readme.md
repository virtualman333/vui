# vui-markdown

VUI 轻量 Markdown 渲染组件

不使用 `v-html`，全部通过结构化节点渲染，因此小程序端同样可用。

## 属性
- content Markdown 源文本
- selectable 文字是否可选中
- showCopy 代码块是否显示复制按钮
- codeMaxHeight 代码块最大高度

## 事件
- copy 代码块复制成功，参数为已复制内容
- link 点击链接，参数为链接地址（组件已同时把地址复制到剪贴板）

## 支持的语法

| 语法 | 说明 |
|------|------|
| `#` ~ `####` 标题 | 一至四级标题 |
| 段落 / 空行分段 | |
| `-` `*` `1.` 列表 | 无序 / 有序列表，支持缩进层级（见下） |
| `- [ ]` `- [x]` | 任务框：渲染成勾选框，`[x]` / `[X]` 为已勾选 |
| `> 引用` | 引用块 |
| 代码围栏 | 带语言标注与复制按钮，超出最大高度可纵向滚动 |
| 表格 | 表头 + 分隔行，超宽时可横向滚动 |
| `---` | 分隔线 |
| `**粗体**` `__粗体__` | |
| `***粗斜体***` `___粗斜体___` | 加粗 + 斜体同时生效（此前会漏出一个多余的 `*` / `_` 给用户看） |
| `*斜体*` `_斜体_` | |
| 行内代码 | 优先于其它行内语法，代码里的方括号不会被当成链接 |
| `[文本](地址)` | 渲染成可点击的链接文本 |
| `![替代文本](图片地址)` | 渲染成替代文本（缺省「图片」），不内联加载远程图片 |

**强调要看定界符的两侧长什么样**，不是「出现了一对相同符号」就算数：

- `_` 出现在**词中间**时不构成强调：`变量 user_name_count 与 my_var 在这里` 原样渲染。
  此前渲染成 `变量 usernamecount 与 my_var 在这里`（两个下划线被吃掉、单词被切成三段斜体），
  `完成 :white_check_mark: 通过` 会变成 `:whitecheckmark:` ——
  **标识符是模型讲代码、讲数据库字段、讲变量名时最常出现的词形**。
- 定界符**紧邻空白**时不构成强调：`计算 3 * 4 * 5 的结果` 原样渲染。此前渲染成
  `计算 3  4  5 的结果`（两个星号消失、中间的数字还变成了斜体）。
- 反过来不误伤：`这是 _重点_ 内容` 照常斜体；`3*4*5` 这种词内 `*` 强调也照常生效
  （CommonMark 里只有 `_` 受词边界限制，`*` 不受）。

### 列表的层级、任务框与编号

缩进即层级：**2 个空格一级**（tab 记 4 格），最多渲染 3 级；超出 3 级的项按第 3 级缩进。
`•` / `◦` / `▪` 是各级无序列表的标记，子层的符号不同，光看符号也能看出从属关系。

```md
- 一级
  - 二级
    - 三级
- [ ] 待办（渲染成空的勾选框）
- [x] 已完成（渲染成打勾的勾选框）
```

有序列表的编号取自原文：`3.` 开头就显示 `3.`（方便接续上一段的编号），
子层各记各的计数器，不会被外层的编号带跑。
**空行分隔的同类列表项属于同一个列表**（这是 Markdown 的通用约定）：`1. 甲` 空行 `2. 乙`
渲染成 1. 甲 / 2. 乙，而不会变成两个各自从 1 开始的列表。

**列表项的续行**：列表项后面紧跟的、**有缩进**的行属于这一项（模型的输出经常把一条长要点
折行，或给某一步补一段说明），会按原文的换行接在上一项正文里：

```md
- 第一步先装依赖，装完再执行下面那条命令，
  注意别在 root 下跑
- 第二步
```

边界（刻意不做的事，避免半吊子支持）：

- **顶格**的非列表行不接 —— 那多半是作者有意另起的段落；
- 空行之后不接（空行只让同类列表变松散，接续的缩进行仍是独立段落）；
- 缩进的**块级起点**（围栏代码块 / 标题 / 分隔线 / 引用 / 表格行）不接：
  「列表项里的嵌套块」本组件不支持，宁可少接不可乱接。

### 链接的点击行为

点击链接会**把地址复制到剪贴板**并提示「链接已复制」，同时抛出 `link` 事件。
复制是各端都成立的动作（小程序端无法直接打开外部网址），需要自定义打开方式的宿主
监听 `link` 自行处理：

```html
<vui-markdown :content="text" @link="onLink" />
```

图片不内联渲染的原因：远程图片在小程序端需要配置域名白名单、在 App 端需要额外设置，
静默加载失败比干脆不显示更难排查。因此图片只渲染替代文本，点击行为与链接一致（复制地址）。

已知取舍：链接地址里含 `)` 时会在该处断句（`[a](x(y))` 只会认到 `x(y`）——
这是行内写法本身的歧义，组件不猜。

## 使用示例

```html
<template>
	<vui-markdown :content="md" :selectable="true" :show-copy="true" @link="onLink" @copy="onCopy" />
</template>

<script>
export default {
	data() {
		return {
			// Markdown 源文本原样传进来即可，换行要保留
			md: '# 标题\n\n正文里的 **粗体** 与 `行内代码`，乘法写作 3 * 4 * 5。\n\n- 列表项\n  - 子项\n- [ ] 待办\n'
		};
	},
	methods: {
		onLink(url) {
			// 地址已同时复制到剪贴板；需要打开外链时在这里自行处理（小程序端不能直接打开网址）
		},
		onCopy(text) {
			// 代码块复制成功
		}
	}
};
</script>
```

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `content` | String | `''` | Markdown 源文本 |
| `selectable` | Boolean | `true` | 文字是否可选中 |
| `showCopy` | Boolean | `true` | 代码块是否显示复制按钮 |
| `codeMaxHeight` | String | `600rpx` | 代码块最大高度，超出可纵向滚动 |

| 事件 | 参数 | 说明 |
|------|------|------|
| `link` | `url` | 点击链接（组件已同时把地址复制到剪贴板） |
| `copy` | `text` | 代码块复制成功 |

更多示例请参考 AI 组件演示页 `pages/demo/ai.vue`。
