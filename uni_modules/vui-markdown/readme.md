# vui-markdown

VUI 轻量 Markdown 渲染组件

不使用 `v-html`，全部通过结构化节点渲染，因此小程序端同样可用。

## 属性
- content Markdown 源文本
- selectable 文字是否可选中
- showCopy 代码块是否显示复制按钮
- codeMaxHeight 代码块最大高度

## 事件
- copy 代码块复制成功，参数为已复制内容
- link 点击链接，参数为链接地址（组件已同时把地址复制到剪贴板）

## 支持的语法

| 语法 | 说明 |
|------|------|
| `#` ~ `####` 标题 | 一至四级标题 |
| 段落 / 空行分段 | |
| `-` `*` `1.` 列表 | 无序 / 有序列表 |
| `> 引用` | 引用块 |
| 代码围栏 | 带语言标注与复制按钮，超出最大高度可纵向滚动 |
| 表格 | 表头 + 分隔行，超宽时可横向滚动 |
| `---` | 分隔线 |
| `**粗体**` `__粗体__` | |
| `*斜体*` `_斜体_` | |
| 行内代码 | 优先于其它行内语法，代码里的方括号不会被当成链接 |
| `[文本](地址)` | 渲染成可点击的链接文本 |
| `![替代文本](图片地址)` | 渲染成替代文本（缺省「图片」），不内联加载远程图片 |

### 链接的点击行为

点击链接会**把地址复制到剪贴板**并提示「链接已复制」，同时抛出 `link` 事件。
复制是各端都成立的动作（小程序端无法直接打开外部网址），需要自定义打开方式的宿主
监听 `link` 自行处理：

```html
<vui-markdown :content="text" @link="onLink" />
```

图片不内联渲染的原因：远程图片在小程序端需要配置域名白名单、在 App 端需要额外设置，
静默加载失败比干脆不显示更难排查。因此图片只渲染替代文本，点击行为与链接一致（复制地址）。

已知取舍：链接地址里含 `)` 时会在该处断句（`[a](x(y))` 只会认到 `x(y`）——
这是行内写法本身的歧义，组件不猜。

## 使用示例

```html
<vui-markdown />
```

更多示例请参考 AI 组件演示页 `pages/demo/ai.vue`。
