## 1.4.0
- **`***粗斜体***` 不再漏出一个多余的星号**：三重定界符此前既匹配不上 `**…**` 也匹配不上 `*…*`，
  正则于是从第二个字符起才认成加粗，多出来的那个 `*` 作为普通文本吐给用户 —— 界面上看到的是
  `*重点*`。`___重点___` 漏下划线同理。现在 `***` / `___` 渲染成加粗 + 斜体（两层修饰会一起
  落到「三重里嵌套的链接 / 行内代码」上），双写与单写的行为不变
- **列表项的续行接回上一项**：列表项后面紧跟的、有缩进的行（模型把一条长要点折行、或给某一步
  补一段说明，这类语料里最常见的写法之一）此前会**把列表拦腰截断** —— 续行掉到列表外面变成
  独立段落（还带着源文件里的缩进空格），后面的项另起一个列表，层级与编号全散。
  现在按原文换行接在上一项正文里；顶格的行、空行之后的缩进行、缩进的块级起点（围栏 / 标题 /
  分隔线 / 引用 / 表格行）都不接 —— 段落与列表的边界不靠猜
- 列表支持**缩进层级**：2 空格一级（tab 记 4 格）、最多 3 级，子层标记换成 `◦` / `▪`。
  此前缩进被直接丢掉，嵌套清单渲染成一串同级圆点，层级信息全没了
- 新增**任务框**：`- [ ]` / `- [x]` 渲染成勾选框（不是把 `[ ]` 原文显示给用户），
  `[x]` / `[X]` 为已勾选
- 有序列表的编号**取自原文**：`3.` 开头就显示 `3.`；子层各记各的计数器
- **空行分隔的同类列表项不再被拆成两个列表**：`1. 甲` 空行 `2. 乙` 编号连续，
  此前会变成两个各自从 1 开始的列表
- 支持行内链接 `[文本](地址)` 与图片 `![替代文本](图片地址)`：此前这两者会被原样显示成
  Markdown 源码（用户看到满屏方括号加网址）。图片渲染为替代文本，不内联加载远程图片
- 新增 `link` 事件：点击链接时抛出，参数为链接地址（同时已复制到剪贴板）
- `**粗体**` / `*斜体*` 里嵌套的链接能正确渲染（单遍扫描不会回头解析强调内部，
  此前会把 `**[文档](…)` 原文显示出来）
- 支持 Markdown 表格（超宽可横向滚动）—— 此前表格整段被当成普通段落，
  用户看到的是满屏 `| 模型 | 分数 |` 原文
- **词中间的下划线不再被当成斜体定界符**：`变量 user_name_count 与 my_var 在这里`
  此前渲染成 `变量 usernamecount 与 my_var 在这里`（两个下划线被吃掉、单词被切成三段斜体），
  `完成 :white_check_mark: 通过` 会变成 `:whitecheckmark:`。标识符是模型讲代码、讲数据库字段、
  讲变量名时最常出现的词形，而这类损坏一个字都不会报错。
  `_` 强调前后是空格时（`这是 _重点_ 内容`）照常生效
- **紧邻空白的定界符不算强调**：`计算 3 * 4 * 5 的结果` 此前渲染成 `计算 3  4  5 的结果` ——
  两个星号消失、中间的数字还变成了斜体；`** 重点 **` 这类带空格的写法同样按字面渲染
- 定界符不成立时**原文照收**（内容一个字都不改），并且相邻的普通文本片段会合并成一个 ——
  此前 `user_name_count` 那样的一串会被切成三段首尾相接的文本节点
