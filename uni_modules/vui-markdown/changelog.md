## 1.4.0
- 列表支持**缩进层级**：2 空格一级（tab 记 4 格）、最多 3 级，子层标记换成 `◦` / `▪`。
  此前缩进被直接丢掉，嵌套清单渲染成一串同级圆点，层级信息全没了
- 新增**任务框**：`- [ ]` / `- [x]` 渲染成勾选框（不是把 `[ ]` 原文显示给用户），
  `[x]` / `[X]` 为已勾选
- 有序列表的编号**取自原文**：`3.` 开头就显示 `3.`；子层各记各的计数器
- **空行分隔的同类列表项不再被拆成两个列表**：`1. 甲` 空行 `2. 乙` 编号连续，
  此前会变成两个各自从 1 开始的列表
- 支持行内链接 `[文本](地址)` 与图片 `![替代文本](图片地址)`：此前这两者会被原样显示成
  Markdown 源码（用户看到满屏方括号加网址）。图片渲染为替代文本，不内联加载远程图片
- 新增 `link` 事件：点击链接时抛出，参数为链接地址（同时已复制到剪贴板）
- `**粗体**` / `*斜体*` 里嵌套的链接能正确渲染（单遍扫描不会回头解析强调内部，
  此前会把 `**[文档](…)` 原文显示出来）
- 支持 Markdown 表格（超宽可横向滚动）—— 此前表格整段被当成普通段落，
  用户看到的是满屏 `| 模型 | 分数 |` 原文
