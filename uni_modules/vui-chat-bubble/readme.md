# vui-chat-bubble

VUI AI 对话消息气泡组件

## 属性
- content 消息文本内容
- placement 气泡位置 left / right，默认 left
- avatar 头像图片地址
- name 名称
- showAvatar 是否显示头像
- status 消息状态 '' / loading / error
- time 时间文本
- maxWidth 气泡最大宽度
- color 气泡背景色
- textColor 文字颜色
- selectable 文字是否可选中

## 使用示例

```html
<vui-chat-bubble />
```

更多示例请参考 AI 组件演示页 `pages/demo/ai.vue`。
