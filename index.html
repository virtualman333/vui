快速开始

复制即可跑，不需要先读完整文档

安装
npm i vui-uniapp
在 pages.json 里启用 easycom
{
  "easycom": {
    "custom": {
      "^vui-(.*)": "vui-uniapp/uni_modules/vui-$1/components/vui-$1/vui-$1.vue"
    }
  }
}
直接用
<template>
  <vui-button type="primary" @click="onClick">开始</vui-button>
</template>
